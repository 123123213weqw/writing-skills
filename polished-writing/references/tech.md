# 硬核科普(tech.md)

受众:愿意跟推导的技术读者。得体 = 推理链无断点、数字无水分。

## 结构

1. 钩子(一个反直觉事实/一句挑衅的问题)
2. 问题定义(为什么值得算)
3. 推导(每步有人话注释;关键步骤编号)
4. 数字落地(至少一组代入计算,标注"可复算")
5. 与已知结论的关系(和文献/常识互证或对比)
6. 局限与适用边界(必须有——没有边界意识的技术文不可信)

## 语言规则

- 术语首次出现给定义或直译;之后直接用
- "显然""易得"禁用——要么给一行推导,要么删
- 图表先于长段文字;每图有自含的 caption
- 承认不确定性:"约""量级""在 X 前提下",比假装精确得体

## 信源纪律

- 每个关键数字:出处(论文/报告/官方);自己的计算:给出公式与参数
- 引用他人的图表注明;转引的数字标"据 XX 转引"
