# AI 腔治理(ai-tone.md)

读者识别 AI 文不需要工具,扫三行就够。本文件列高频指纹与替换法。**规则:写完全文后必须过一遍本清单;宁可写得"不像AI"而平淡,不要"像AI"而华丽。**

## 一、词汇指纹(出现即改)

| AI 腔 | 为什么露馅 | 人话替换 |
|---|---|---|
| 值得注意的是 / 值得一提的是 | 高频到成梗 | 直接说事实;真值得注意就说明为什么 |
| 本质上 / 归根结底 | 万能解释器前缀 | 删掉,直接给结论;或"说白了" |
| 不仅仅是 X,更是 Y | 递进强迫症 | 二选一,留重的那个 |
| 如果说 X 是…那么 Y 就是… | 比喻对仗癖 | 一个比喻就够,别成对出 |
| 深入剖析 / 深度解析 / 全方位 | 营销腔 | 删;写了多深读者自己看得见 |
| 在这个…的时代 / 随着…的发展 | 万能开头 | 直接进场景 |
| 无疑 / 无疑是 | 虚假确定性 | 删,或给数据 |
| 令人惊叹 / 令人印象深刻 | AI 的兴奋很廉价 | 让事实自己惊人,删形容 |
| 让我们… / 我们不妨 | 课堂导览腔 | 删,直接做 |
| 你可能会想 / 你也许会问 | 自问自答强迫症 | 一篇文章至多一次,最好零次 |
| 赋能 / 抓手 / 闭环 / 沉淀 | 黑话污染 | 说人话:给谁、什么能力 |
| 极大地 / 有效地 / 显著地(无数据) | 空洞副词 | 给数字,或删副词 |

## 二、结构八股(重排而非润色)

- **首先/其次/最后**:直接用内容顺序或小标题,删导航词
- **每段结尾小结**:段尾复述段首 = 废话翻倍。删
- **结尾升华**:"在这个充满挑战与机遇的时代…"——全删。结尾停在具体处
- **列表瘾**:连续三个以上 bullet 时问自己:这是真清单,还是懒得写连贯句子?叙事内容用段落
- **三段排比**("更快、更强、更稳"):留一个最准的
- **平衡癖**:每给一个观点就"当然,另一方面…"——敢下判断;反例放进正文逻辑里,不和稀泥

## 三、标点与格式指纹

- 破折号(——)一段至多一次;冒号别连续出现
- 给普通词加引号("智能"、"优化")是 AI 标配,只在真引述/反讽时用
- 加粗一段至多一处(主 SKILL 已有,此处是自查高频项)
- 每个小节都是同样长度 = AI 节奏;人类写作有长短呼吸

## 四、人类写作的正面特征(往这里靠)

1. **具体经验**:"我用它跑了一晚上"比"经过长期使用"可信一百倍
2. **短句爆发**:关键处敢用三五字短句。人会冲动,AI 会铺陈
3. **不完美的节奏**:有跑题半句再拉回来的松弛感;全文工整=机器
4. **敢下判断,留一个出口**:"我选 A。要是你的场景是 X,那另说"——而不是"各有优劣"
5. **个人语癖**:允许一两个固定口头禅反复出现(反而形成作者识别度)
6. **承认不知道**:"这块我没查到可靠数字"——AI 从不说自己不知道,这恰恰是最人类的句子

## 五、终检三问(交付前)

1. 随机抽三段大声读——像不像一个具体的人在跟你说话?像谁?说不出像谁就重写
2. 把所有形容词遮住,文章信息量掉了吗?没掉说明形容词是装饰,删
3. 这篇文章的第一句,会不会出现在一百篇别的 AI 文章里?会,就换
