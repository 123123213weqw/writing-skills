# 得体写作(Polished Writing)

在起草或修改任何长文之前通读本文件。目标只有一句话:**读者读完记得住核心观点、信任作者、不被任何一处措辞绊住**。

## 第一步:判断文章类型

先问(或从上下文判断)这篇文章属于哪类,不同类型的"得体"完全不同:

| 类型 | 语气 | 结构重心 | 参考细分 |
|---|---|---|---|
| 硬核科普 | 沉稳、推理链完整 | 推导、数据、出处 | read references/tech.md |
| 通俗科普 | 像给朋友讲,先直觉后知识 | 故事线、比喻、案例 | read references/popular.md |
| 开源/产品宣传 | 自信但只说可查证的事实 | 差异点、截图证据、上手路径 | read references/promo.md |
| 热点评论 | 快、准、克制 | 时间线事实 → 机制分析 → 分寸 | read references/hotspot.md |

判断后先读对应 reference,再动笔。

## 通用风格规则(所有类型生效)

### 语言:人话优先,术语殿后

- 每个新概念先用一句**生活化直觉**落地,再给术语。比喻当锚点(一句话),不展开成段
- 公式前必有一句人话预告它在说什么;公式后必有一句它意味着什么
- 段落别超过 6 行;连续两段没有具体数字/案例/比喻,就要砍
- 中文长文一律用逗号","和句号"。",混入英文标点是事故(代码与专有名词除外)

### 排版(中文写作的硬规则)

- 中文与数字、英文单词之间加空格:"约 3.5% 的持股"而非"约3.5%的持股"
- 数字千分位:100,000;百分数用 % 并与数字相连:74.5%
- 专有名词保持原文首次出现加中文注释:McNemar 检验(配对显著性检验)
- 强调用**加粗**,不用下划线/斜体(中文斜体不可读);一段至多一处加粗

### 得体红线

1. **绝对化禁用**:不写"最""第一""碾压""吊打",除非后面紧跟可查证的数据。对比类内容只写公开可查的事实,拿不准就写"公开信息显示"
2. **不利数据的呈现**:诚实但主次分明——先说结论的正确解读(如"统计上等价"),不利细节放次要位置,不删也不当标题。把"诚实"写成"自我贬损"是失败(实例:p=1.0 应解读为"重实现零质量损失",而不是"没赢")
3. **敏感主题中性化**:涉及政策、金融监管、加密货币、地缘的内容:只描述机制与数据,不评价对错,不写操作指引,开头结尾加"不构成建议"类声明
4. **不预设立场攻击**:竞品/对家只攻击"形态局限"(如终端产品做不了 GUI),不揣测动机,不用阴谋论句式(可以写"无法证实",不可以写"就是他们干的")

### 诚信规则(违反即废稿)

- 所有数字必须经过计算或给出处,禁止心算进文
- 每个关键论断可溯源:论文/报告/官方公告,文末列信源
- 案例数字交叉核实;单一来源的数字标注"据 XX 报道"
- 时间敏感内容标注"截至 YYYY.MM.DD"

### 结构模板

- **标题**:钩子优先——悬念、反直觉、具体数字、直接对标,任选其一。超过 25 字考虑砍副标
- **开头**:三行内出现钩子(问题/悖论/数字);第一段不超过 5 行
- **正文**:每节一个论点;节标题可读成提纲
- **结尾**:一段总结 + 读者行动(关注/讨论/star,选一个,别贪)
- **系列文**:文末带系列目录与下期预告;预告必须兑现

## AI 腔治理(所有类型、最高优先级)

读者扫三行就能识别 AI 文——词汇指纹("值得注意的是""不仅仅是 X 更是 Y")、结构八股(首先/其次/最后、段尾小结、结尾升华)、教师爷腔("让我们""你可能会想")是最大破绽。动笔前 read references/ai-tone.md 通读黑名单;完稿后必须按其"终检三问"过一遍——这一步不可跳过,腔调破绽比错别字致命。

## 平台适配

写知乎前必读两个文件:read references/zhihu-style.md(**高赞文的实证风格**——开头四模式、1-3 行段落、设问推进、签名式结尾,全部来自真实语料分析,优先级最高),以及 read references/zhihu.md(公式 ASCII 化、表格限制、风控敏感区、发布行为规范)。写其他平台时按平台调性微调,但通用规则不变。

**知乎段落规则覆盖通用规则**:写知乎时段落上限 3 行(不是 6 行),单句成段制造节奏;推进用设问链,不用"首先/其次"。

## 自查清单(交付前)

- [ ] **AI 腔终检三问已过**(read references/ai-tone.md 第五节)
- [ ] 删掉了所有没有数据支撑的形容词
- [ ] 每个比喻都能一句话讲完
- [ ] 三个随机抽查的数字都能给出处或复算
- [ ] 大声读第一段,10 秒内说不出"这篇讲什么"就重写开头
- [ ] 敏感主题声明的位置正确(开头或结尾)
- [ ] 结尾只有一个行动号召
